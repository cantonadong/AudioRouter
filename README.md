# AudioRouter

<img width="549" height="437" alt="image" src="https://github.com/user-attachments/assets/713faf9b-2497-4378-8cca-e90f36c5f731" />

Windows 10/11 原生音量工具，Rust + Win32/GDI。1.0 已接入真实音频数据。

双击根目录 AudioRouter.exe。面板宽 360 逻辑像素，行高 44，按显示器 DPI 缩放。

- 拖动设备或应用滑块修改真实音量，点击图标静音；点击设备名称折叠列表。
- 应用与设备音量相同时跟随设备；较低时保留独立目标，设备音量恢复后恢复目标。
- 右键设备设置默认输出；右键应用选择固定输出或跟随默认。固定设备断开回退默认，重连恢复偏好。
- 顶部菜单提供系统新旧音频设置、开机启动、刷新和退出；F5 刷新。
- 关闭、Escape 或失焦收起到托盘；托盘左键打开，右键退出。滚轮滚动列表，拖动标题移动。
- Tab 选择滑块，方向键调整，Shift+方向键调整 10，Home/End 调至 0/100，空格静音。

绿色版配置保存在 EXE 同目录的 AudioRouter.ini，记录默认设备、应用指定输出、应用音量和设备折叠状态；日志也位于 EXE 同目录。首次启动新版时自动迁移原 %LOCALAPPDATA%/AudioRouter/preferences.txt（或旧 WinSpeaker 配置），已有 INI 时只读取同目录 INI。启动时仅在当前默认设备与 INI 记录不同且设备可用时恢复设备。开机启动由用户主动开启，写入当前用户 Run 项。系统声音路由由 Windows 管理；某些应用需要重新播放或重建音频流才能响应输出切换。

build.bat 使用 Python 标准库和 Rust GNU 工具链离线编译，结束旧进程并覆盖同一个 EXE。无第三方 Rust crate、浏览器内核或后台定期轮询；空闲阻塞等待事件。

已完成源码审查和 release 编译，未运行测试或启动应用。实际音频行为、DPI 和内存/CPU 占用等待用户运行验证。

窗口随内容增高，仅超出显示器可用区域时显示滚动条。悬停应用或设备后，滚轮每格调整 2% 音量。应用音量为设备音量下的独立百分比，默认 100%，不与设备滑块联动；静音应用显示 0。当前默认设备排在面板底部。托盘右键菜单随系统明暗主题显示，可切换默认设备、指定应用输出、切换开机启动及打开新版或旧版声音设置。
